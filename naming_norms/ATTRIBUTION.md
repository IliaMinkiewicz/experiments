# Источники изображений

Репозиторий с заданием публичный (этого требует GitHub Pages), поэтому изображения
в папках `img/` и `train/` фактически публикуются. Ниже — их происхождение и условия.

## Стимулы из THINGS-Mooney (74 изображения)

Linde-Domingo, J.\*, Ortiz-Tudela, J.\*, Völler, J., & González-García, C. (2025).
THINGS-Mooney database (v1.1). Zenodo. https://doi.org/10.5281/zenodo.15340222
Лицензия MIT. Исходники — license-free (CC0) изображения из THINGSplus.

Hebart, M. N., et al. (2019). THINGS: A database of 1,854 object concepts and more than
26,000 naturalistic object images. PLOS ONE, 14(10), e0223792.

Stoinski, L. M., Perkuhn, J., & Hebart, M. N. (2024). THINGSplus: New norms and metadata
for the THINGS database. Behavior Research Methods, 56, 1583–1603.

## Стимулы и якоря из базы Van de Cruys (20 + 12 изображений)

Van de Cruys, S., Damiano, C., Boddez, Y., Król, M., Goetschalckx, L., & Wagemans, J. (2021).
Visual affects: Linking curiosity, Aha-Erlebnis, and memory through information gain.
Cognition, 212, 104698. Материалы: https://osf.io/hm2kb/

Исходные фотографии загружены авторами с Flickr с лицензией
**Attribution-NonCommercial (CC BY-NC)**, часть — из базы MemCat.
Использование здесь некоммерческое, в научных целях, с указанием авторства.
При любом коммерческом использовании требуется согласие правообладателей.

## Тренировочные изображения (3)

Из CC0-набора THINGSplus (`images_THINGSplus-CC0.zip`, лицензия CC0),
полученные через репозиторий THINGS-Mooney.

## Обработка

Все изображения приведены к серому, обрезаны до форматов 350×250 / 350×350 / 250×350
и уменьшены. Скрипты обработки — в основном проекте.
